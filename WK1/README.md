# Python Exercises – Week 1

This folder contains basic Python exercises for learning input handling, variables, calculations, and printing results.

---

## A1_T2.py  
**Description:**  
Simple variable assignment and printing.

**Features:**  
- Assigns two names  
- Prints them individually  
- Prints them together  
- Prints a sentence using both variables  

---

## A1_T3.py  
**Description:**  
Calculates the remainder of a number when divided by 2.

**Features:**  
- Asks user for an integer  
- Converts input to integer  
- Uses modulo operator `%`  
- Prints the remainder  

---

## A1_T4.py  
**Description:**  
Calculates car fuel consumption in liters per 100 km.

**Features:**  
- Asks user for travel distance  
- Asks user for fuel usage  
- Calculates consumption using `(FuelUsage / Distance) * 100`  
- Prints result in “x l per 100 km” format
